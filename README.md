# AniMichi 🌸

Next-Gen Anime & Manga Dashboard powered by Node.js, Express, and SQLite.

## 🚀 Features

* **Anime & Manga Tracking:** Browse and manage your favorite titles in one place.
* **User Authentication:** Secure local login and user profiles.
* **Local Database:** Fast and lightweight data management using SQLite.
* **Modern Dashboard:** Clean, responsive interface for a seamless experience.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express
* **Database:** SQLite
* **Frontend:** HTML, CSS, JavaScript *(update if using a framework like React)*
